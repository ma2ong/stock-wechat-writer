# stock-wechat-writer

面向中文财经自媒体的 `Claude Code` skill，一键生成 A股 / 港股 / 美股复盘、收评、行情分析公众号文章。

融合 **DeepEar / alphaear 实时信号**、**财联社 / 雪球实时新闻（opencli）**、**akshare / yfinance 行情数据**，按 vibe-writer-pro 写作体系输出有立场、有判断、公众号读者愿意看完并转发的复盘文章。

---

## 适用任务

在 Claude Code 里直接说：

```text
写今天的A股复盘
生成今天的行情分析文章
写盘后总结 / 收评 / 明日展望
做一篇公众号股票复盘（含封面图）
补封面并发到草稿箱
```

---

## 核心能力

### 1. 实时多源行情核对

写作前先采集数据、整理事实卡片，卡片写不清楚不进入写作阶段。

| 数据源 | 用途 | 工具 |
|--------|------|------|
| akshare | 指数、成交额、板块排行、宽度 | Python |
| opencli xueqiu / cailian | 雪球热议、财联社要闻 | CLI |
| alphaear skill | DeepEar 高置信度信号 | Skill |
| yfinance | 港股 / 美股 / ADR | Python |

关键数字至少两种来源交叉确认，"板块涨幅榜第一 ≠ 真正主线"。

### 2. 唯一主判断

每篇复盘只保留一个核心判断。推荐句式：

- 不是 X，而是 Y
- 表面看是 X，本质上是 Y
- 如果只看涨幅榜，很容易误判——真正的主线是 Y

### 3. 四层自检（四遍独立过）

| 层级 | 检查重点 |
|------|---------|
| L1 硬性规则 | 禁用词、具体数字、无套话结构 |
| L2 节奏口语 | 段落≤4行、长句拆分、口语化转折 |
| L3 内容质量 | 主线有支撑、至少2个具名案例、驱动有来源 |
| L4 活人感 | 有立场、有读者视角、有反直觉角度 |

四遍不能合并成一次扫描。L4 是最容易被跳过、也最重要的一关。

### 4. 七维传播力评估（必做）

| 维度 | 标准 |
|------|------|
| D1 标题钩子 | 信息差 / 情绪 / 数字，让持仓读者必须点开 |
| D2 开头留人 | 前3行无废话，直给反直觉判断或关键数字 |
| D3 内容密度 | 每段有具体数字或事件，段落2-4行 |
| D4 情绪触发 | 触发焦虑 / 共鸣 / 好奇 / 确认感之一 |
| D5 互动引导 | 结尾有开放性问题引导留言 |
| D6 关注转化 | 有系列感或人设差异 |
| D7 裂变单元 | 有一句话可单独截图转发 |

### 5. 标题公式（HKR 三维评估）

四个可用公式，按 **H（快感）/ K（信息）/ R（共鸣）** 选最高分：

| 公式 | 示例 |
|------|------|
| 数字+判断翻转 | `3.25万亿爆了，主线彻底换了` |
| 反直觉开头 | `不是普涨，真正的主线回来了` |
| 警示信号 | `今天A股最危险的信号，不是大涨，而是太一致了` |
| 主线切换 | `消费退潮，科技接棒——今天的分歧在这里` |

### 6. 封面图生成（HTML + Playwright）

封面走 HTML 模板 → Playwright 截图，不依赖 AI 绘图，文字和数字精准可控。

- 固定尺寸 900×500px
- 深色渐变底（三套金融配色方案可选）
- 核心判断大字 + 日期 + 账号标注

### 7. 全流程输出

```
正文 Markdown
→ md2wechat-skill 转公众号 HTML
→ 封面 PNG（Playwright 截图）
→ pre_publish_check.py 发稿前检查
→ push_stock_review_draft.py 推送草稿箱
```

## 关键约束

- 写之前必须核对当日真实行情，事实卡片写不清楚不进入写作
- 不把涨幅榜第一直接当主线，要看成交量和龙头
- 正文至少2个具名案例（公司名/股票代码+具体数字）
- 发稿前必须跑 `pre_publish_check.py`，0 failures 才能推送
- 所有内容仅供信息整理与复盘参考，不构成投资建议

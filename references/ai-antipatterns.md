# 财经内容 AI 味消除手册

财经内容 AI 味的本质：把不确定的市场说得太确定，把有争议的判断说得太客观，把具体的数字藏在模糊形容词里。

---

## 一、禁用词与替换

### 1.1 模糊形容词（必须换成具体数字）

| 禁用 | 替换方式 |
|------|---------|
| 大幅上涨 / 显著上涨 | 涨X% / 涨X点 |
| 成交量明显放大 | 成交额X亿，环比+X% |
| 市场情绪高涨 | 涨停X家，跌停X家 |
| 强势反弹 | 收复X点 / 反弹X% |
| 回落幅度较大 | 跌X% / 跌至X点 |
| 资金明显流入 / 流出 | 北向资金净买入/净卖出X亿 |

### 1.2 空话套语（直接删除）

- 行情表现活跃
- 投资者情绪显著修复
- 多个板块实现上涨
- 市场整体表现不俗
- 后续行情值得关注
- 整体来看，市场...
- 综上所述
- 不难发现
- 值得关注的是
- 总体而言

### 1.3 机构腔（改成口语）

| 禁用（机构腔） | 替换（口语） |
|------|------|
| 多重因素共振 | 今天同时发生了X和Y |
| 宏观逻辑支撑 | 背后是XX政策/消息 |
| 助力板块上行 | 推着这个板块往上走 |
| 旨在提振市场信心 | 目的就是让市场别跌 |
| 叠加海外市场共鸣 | 加上美股昨晚也涨了 |
| 情绪面持续改善 | 今天涨停家数从X增加到Y |
| 实现结构性机会 | 某某板块有机会，其他的没有 |

### 1.4 禁用句式结构

| 禁用结构 | 替换方式 |
|------|------|
| 首先…其次…再次…最后… | 直接说最重要的那个 |
| 一方面…另一方面… | 拆成两句话，各说各的 |
| 在当前市场环境下… | 直接切入事实 |
| 近期A股市场… | 写今天发生了什么 |
| 随着XX持续推进… | 直接说结果 |
| 不是X，是Y（对比判断句） | 直接说清楚是什么，省掉对比结构。"不是维持，是升温"→"买力还在增加"；"不是守仓，是在加"→"主力持续加仓" |

### 1.5 标点禁用

- 不用"！！"（连用感叹号）
- 不用"……"（省略号代替停顿，用句号）
- 不用独占一行的冒号引出下文
- 慎用括号插入说明，改成破折号或单独一句

## 二、财经内容特有 AI 味

### 2.1 "安全话术" AI 味

AI 常在判断后面加免责，显得没有立场：

- 禁用："市场走势存在不确定性，投资者需谨慎" — 风险提示只在文末加一次，正文不重复
- 禁用："仅供参考，不构成投资建议" — 放风险提示区，正文不穿插
- 禁用：每段都加"但也需注意..." — 选一处重要风险说清楚，不分散

### 2.2 "数据平铺" AI 味

把采集到的数据全部罗列：
- 禁用：一段话写了6个指数的点位和涨跌幅
- 正确：选1-2个最能说明问题的数字，其他服务于论点

### 2.3 "伪客观" AI 味

表面中立，实际没有判断：
- 禁用："市场分化明显，强弱分歧加剧"
- 正确：说清楚谁强谁弱、为什么，以及这对后市意味着什么

### 2.4 "主线误判" AI 味

把涨幅榜第一当主线，不看成交量：
- 禁用："今日领涨的XX板块成为市场主线"（只因排名第一）
- 正确：成交额占比、龙头股是否有连板、是否有产业逻辑支撑

## 三、活人感替换示例

把"AI播报腔"改成"有判断的人在说话"：

**改前：**
> 今日A股三大指数普遍收涨，科技板块表现强势，成交额达到3.1万亿，市场整体情绪较为乐观。

**改后：**
> 3.1万亿，这是今年以来第三次破3万亿。但真正值得注意的不是指数涨了多少——今天的主线悄悄从消费切向了科技，有些人可能还没反应过来。

---

**改前：**
> 整体来看，明日市场仍存在一定的不确定性，投资者需密切关注相关板块的动态变化。

**改后：**
> 明天最关键的只有一件事：科创板的量能能不能接住今天的情绪。如果缩量，这波大概率是脉冲，不是趋势。

## 四、写完对照清单（L1-L4 快查版）

**L1（硬性规则）：** 无禁用词 / 数字具体 / 无"首先其次最后" / 标点正常  
**L2（节奏）：** 段落≤4行 / 长句拆开 / 开头不是导语  
**L3（内容）：** 主线有支撑 / 驱动有来源 / 明日观察点可验证  
**L4（活人感）：** 有立场 / 有读者视角 / 有反直觉角度 / 读起来像人说话

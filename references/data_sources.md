# 数据源手册

这份文件只回答一个问题：

**写当天复盘时，事实该从哪里核对。**

不要把它当成完整 API 文档，也不要把所有抓数代码堆在这里。重点是数据源优先级、适用场景和常见误区。

---

## 一、推荐数据源优先级

### 第一优先级：行情事实

用于核对：

- 指数点位
- 涨跌幅
- 两市成交额
- 上涨 / 下跌家数
- 板块涨跌排行
- 北向资金

推荐来源：

1. `akshare`
2. 实时财经媒体收盘口径
3. 交易所或公开行情页

### 第二优先级：盘面解释

用于核对：

- 当天主线板块为什么强
- 是否有政策 / 消息 / 海外映射催化
- 盘中或收盘后的市场解释

推荐来源：

1. 财联社
2. 华尔街见闻
3. 雪球热议
4. DeepEar 信号

### 第三优先级：辅助验证

用于补充：

- 代表个股
- 行业联动
- 舆情热度

推荐来源：

1. 雪球
2. yfinance
3. 其他公开新闻页

---

## 二、不同数据源各自负责什么

### 1. akshare

这是默认的主力行情源。

适合拿：

- 指数收盘点位
- 指数涨跌幅
- 板块涨跌排行
- A股全市场快照
- 北向资金

适用判断：

- 今天市场整体强不强
- 成交额有没有放大
- 哪些板块在涨，哪些在跌

注意：

- 板块涨幅榜第一，不等于市场真实主线
- 单靠 `akshare` 不足以解释“为什么今天这么走”

### 2. 实时财经媒体

适合拿：

- 收盘口径确认
- 盘后总结
- 当天市场解释
- 重要政策 / 产业消息

重点用途：

- 给 `akshare` 的数字做二次确认
- 判断主线是情绪、事件还是产业逻辑驱动

注意：

- 同一时间不同媒体口径可能略有差异
- 优先使用更晚、离收盘更近的口径

### 3. DeepEar

适合拿：

- 高置信度市场信号
- 某个方向的情绪或主题提示
- 可关注标的线索

重点用途：

- 辅助解释
- 补充“市场在交易什么”

不要这样用：

- 不要把 DeepEar 信号直接当成文章核心事实
- 不要用它替代指数、成交额、板块、涨跌家数这些硬数据

### 4. yfinance

适合拿：

- 港股 / 美股 / ADR
- 海外映射公司
- 海外市场涨跌背景

重点用途：

- 节假日期间海外映射
- A股科技线、资源线、外盘风险偏好的旁证

### 5. 雪球 / 社区讨论

适合拿：

- 当天市场情绪
- 哪些票和哪些概念最热
- 投资者关注点

重点用途：

- 辅助理解情绪
- 找市场最聚焦的方向

不要这样用：

- 不要把社区情绪当成事实来源

## 三、写复盘时必须核对的字段

最低限度必须确认：

1. 上证指数
2. 深成指
3. 创业板或成长核心指数
4. 两市成交额
5. 上涨 / 下跌家数
6. 领涨主线
7. 领跌方向
8. 一个核心驱动

如果缺了其中两项以上，不要直接进入写作。

---

## 四、常见误判

### 1. 把涨幅榜第一当成主线

主线判断要看：

- 资金是否集中
- 是否有产业链扩散
- 是否有龙头带动
- 是否对指数和情绪有影响

### 2. 把消息刺激当成趋势反转

一天的大涨，可能只是新闻脉冲，不一定是中期主线。

### 3. 只看指数，不看宽度

指数上涨不代表大多数股票都强，必须看市场宽度。

### 4. 只看板块，不看成交额

没有量能配合的上涨，很多时候只是轮动，不是主升。

---

## 五、建议使用方式

写当天复盘时，按这个顺序取数据：

1. 用 `akshare` 拿指数、成交额、板块、宽度
2. 用财经媒体确认收盘口径
3. 用新闻和 DeepEar 补主线解释
4. 如需写海外映射，再补 `yfinance`

最后整理成事实卡片，再进入正文写作。

# 风险否决规则

这份规则用于决定“即使看起来有机会，也不能推荐”的情况。

核心原则：风险否决优先于买点。宁可少写机会，不把高风险票放进推荐池。

---

## 一票否决

出现以下任一情况，正文只能写“回避/观察/等修复”，不能写“买入/低吸/加仓/可做/推荐”。

| 风险 | 判定标准 | 正文写法 |
|---|---|---|
| 高位放量长阴 | 高位大跌、成交额显著放大、收盘接近低点 | 等止跌和反包，不接第一根放量阴线 |
| 放量长上影 | 冲高回落，量能放大，收盘远离高点 | 说明上方抛压重，只能看修复 |
| 龙头断板退潮 | 龙头/妖股断板，高位股大面扩散 | 回避跟风票，等亏钱效应收敛 |
| 主线集体破位 | 核心股跌破关键均线或平台，板块无承接 | 主线弱化，不能用个别反抽当买点 |
| 单票独涨 | 板块不跟、核心股不动、只有单票涨停 | 孤立脉冲，不进推荐池 |
| 低位一日反弹 | 前期连续弱势，只涨一天，无连续反转证据 | 只能写反弹观察，不能写机会 |
| 重大基本面风险 | 减持、监管、业绩变脸、解禁、诉讼等确定风险 | 风险优先，买点失效 |
| 消息未兑现 | 只有传闻或社交热议，没有价格和成交额响应 | 不做主判断，不进标题和推荐 |

---

## 高位分歧处理

高位强趋势票出现大分歧时，不马上判死，也不马上抄底。

处理顺序：

1. 先看是否属于当前主线核心。
2. 再看分歧当天是缩量还是放量。
3. 再看收盘位置：接近高点是承接，接近低点是卖压。
4. 最后看次日能否修复关键位。

可写成：

```markdown
逻辑没有坏，但价格结构先弱了。
如果明天能收回[关键位]，说明资金愿意修复。
如果继续放量跌破[风险位]，先按退潮处理，不急着接。
```

## 低位反转门槛

低位票只有满足至少三类证据，才允许从“剔除”升为“观察”；满足更高强度后才允许写“可试错”。

| 证据 | 最低要求 |
|---|---|
| 图形 | 放量突破平台，或重新站回 5/10/20 日均线后连续 2-3 日不破 |
| 资金 | 成交额明显放大，回踩缩量，主动买盘强于卖盘 |
| 板块 | 同方向有核心股和梯队，不是单票独涨 |
| 情绪 | 从亏钱效应转为赚钱效应，断板/大面不扩散 |

没有这些证据，连提名都要谨慎。

---

## 操作词安全线

出现操作词时必须同时写清楚：

1. 触发条件：站回什么位置、突破什么平台、回踩哪条均线。
2. 风险位：跌破哪里说明判断失效。
3. 仓位语气：只能写“小仓试错/观察/等确认”，不能无条件喊单。
4. 板块配合：同板块核心股是否同步修复或强化。

不满足这四条，操作词必须删除，改成“观察”。

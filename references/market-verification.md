# 实时行情核对手册

这一步是整个 skill 最容易失真的地方。

如果行情核对不硬，后面的文章越流畅，偏差越大。

## 一、必须核对的 8 个字段

1. 上证指数收盘点位和涨跌幅
2. 深成指收盘点位和涨跌幅
3. 创业板或纳指类核心成长指数涨跌幅
4. 两市成交额
5. 上涨 / 下跌家数，或可替代的市场宽度指标
6. 领涨主线
7. 领跌方向
8. 一个能解释盘面结构的催化因素

## 二、双重确认规则

关键数字至少两种来源交叉确认：

- 指数、成交额：`akshare` + 财经媒体收评
- 主线板块：板块排行 + 当日收评文字
- 驱动因素：新闻 / 事件 / 海外映射 / 资金流向

如果两种来源冲突：

1. 优先使用时间更晚的收盘数据
2. 优先使用同一口径的数据源
3. 在正文中避免写不确定数字，改写成趋势判断

## 三、不要混淆的几组概念

### 1. 板块涨幅第一，不等于主线第一

主线判断要看：

- 资金是否集中
- 是否有产业链扩散
- 是否有核心龙头带动
- 是否能影响指数和情绪

### 2. 指数大涨，不等于全面牛市

要看：

- 成交额有没有同步放大
- 宽度是否改善
- 高弹性方向是否领涨
- 防御板块是否被抽血

### 3. 事件驱动，不等于可持续主升

若只是单日消息刺激，要区分：

- 一日脉冲
- 中期主线

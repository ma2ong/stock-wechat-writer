# 实时行情核对手册

如果行情核对不硬，后面的文章越流畅，偏差越大。

## 必须核对的 8 个字段

1. 上证指数收盘点位和涨跌幅
2. 深成指收盘点位和涨跌幅
3. 创业板或成长核心指数涨跌幅
4. 两市成交额
5. 上涨 / 下跌家数，或可替代的市场宽度指标
6. 领涨主线
7. 领跌方向
8. 一个能解释盘面结构的催化因素

## 双重确认规则

关键数字至少两种来源交叉确认：

- 指数、成交额：`akshare` + 财经媒体收评
- 主线板块：板块排行 + 当日收评文字
- 驱动因素：新闻 / 事件 / 海外映射 / 资金流向

# 实时行情核对手册

如果行情核对不硬，后面的文章越流畅，偏差越大。

## 必须核对的 8 个字段

1. 上证指数收盘点位和涨跌幅
2. 深成指收盘点位和涨跌幅
3. 创业板或成长核心指数涨跌幅
4. 两市成交额
5. 上涨 / 下跌家数，或可替代的市场宽度指标
6. 领涨主线
7. 领跌方向
8. 一个能解释盘面结构的催化因素

如果文章要写关注标的，还必须额外核对 6 个趋势字段：

1. 标的是否属于当前强主线，而不是前期弱势反弹
2. 近 3-5 日走势是强化、持平、弱化还是反转
3. 当前价格与 5/10/20 日均线、平台和前高的关系
4. 成交额、主动买盘/卖盘、主力流向是否支持趋势延续
5. 同板块核心股是否共振，是否只有单票独涨
6. 情绪位置：连板/妖股是否退潮，高位股亏钱效应是否扩散

还必须做一次“板块身份校验”：确认写的是哪条真实交易线。例：算电协同要核对大唐发电、华电辽能、华电能源、韶能股份、晋控电力、京能电力等情绪核心；不能拿长江电力、华能水电、中国核电这类红利防守票替代。

## 股票代码-名称强校验

凡是正文出现 `公司名（股票代码）`，发布前必须用东方财富、同花顺、Wind/万得或交易所信息做代码-名称匹配校验。

这是硬门槛，不是风格建议。出现以下情况必须重写：

- 公司名和代码不匹配。例如 `大普微（688469）` 是错误写法，因为 `688469` 对应的是芯联集成-U；大普微对应 `301666`。
- 股票简称缺少关键后缀导致歧义。例如带 `-U`、`-UW`、`A`、`B` 的股票，首次出现时尽量按行情软件简称写全。
- 只凭财经号、截图、LLM 输出写代码，不查行情源。
- 把相邻产业链股票误写成同一家公司，例如供应商、参股方、地方国资映射股混成直接受益股。

执行方式：

```bash
python scripts/pre_publish_check.py --article output/stock_review_YYYYMMDD.md
```

检查脚本会从正文里提取 `公司名（6位代码）`，调用东方财富实时行情接口和本地缓存校验简称。若代码-名称不匹配，直接失败，不允许推送。

如果东方财富接口临时不可用，可以用同花顺、Wind/万得、交易所公告或 OpenCLI/MCP 手工核对，但必须在事实卡片里写清楚替代来源，并把核对后的简称补入 `references/stock_name_cache.json`。不要为了发稿跳过校验。

未能校验的代码默认按失败处理。只有已经手工核对并写明来源时，才允许临时使用：

```bash
python scripts/pre_publish_check.py --article output/stock_review_YYYYMMDD.md --allow-unverified-stock-names
```

## 资金与榜单口径校验

涉及以下说法时，必须写清楚来源或在事实卡片保留来源，不允许凭模型推断：

- “外资买入”“北向买入”“深股通专用买入”
- “机构专用席位买入/卖出”
- “龙虎榜显示”
- “主力净流入/净流出”
- “融资盘持续堆积”

规则：

- 龙虎榜资金只来自交易所、东方财富龙虎榜、同花顺龙虎榜或 Wind。
- 主力资金流只作为辅助，不等于真实机构买卖；正文里不要把“主力净流入”写成“机构确认”。
- 外资/北向/深股通口径要区分：陆股通持股、盘中资金流、龙虎榜席位不是一回事。
- 没有来源时，只能写“成交额放大/资金承接明显”，不能写具体席位或外资金额。

完成事实核对后，必须继续填写 `pre-writing-judgement-card.md`。事实卡片回答“发生了什么”，判断卡回答“今天该写什么、能不能推荐、等什么信号”。

风险否决按 `risk-veto-rules.md` 执行。只要触发一票否决项，即使板块热度高，也不能给出正向操作建议。

## 深度分析硬门槛

任何“可关注/可低吸/可试错”的方向，都必须先完成六维检查：

| 维度 | 必查问题 |
|---|---|
| 盘面 | 指数、成交额、宽度是否支持风险偏好 |
| 资金 | 成交额、放量/缩量、主动买卖盘、主力流向是否支持 |
| 情绪 | 涨停梯队、连板高度、妖股/龙头是否断板，亏钱效应是否扩散 |
| 技术 | 5/10/20 日均线、平台、前高、缺口、长上影/放量阴线 |
| 横向 | 同板块核心股谁强谁弱，是否只有单票独涨 |
| 纵向 | 近 3-5 日是强化、分歧、退潮还是反转 |

结论规则：

- 六维里至少 4 维支持，才能写“可关注/可试错”。
- 情绪和资金任一项明显转弱，只能写“等确认”，不能追。
- 技术破位且板块不共振，直接剔除。
- 只有消息或涨幅，没有资金/情绪/图形确认，不能推荐。

## 双重确认规则

关键数字至少两种来源交叉确认：

- 指数、成交额：`akshare` + 财经媒体收评
- 主线板块：板块排行 + 当日收评文字
- 驱动因素：新闻 / 事件 / 海外映射 / 资金流向

# 写作前判断卡

这张卡必须在正文之前完成。它不是给读者看的内容，而是给写作者判断“今天到底该写什么、能不能推荐”的决策底稿。

规则：判断卡写不清楚，不进入正文。没有机会时，正文可以短，但判断卡不能省。

---

## 一、市场类型

先给当天盘面打一个标签，只能选最贴近的一类：

| 类型 | 识别信号 | 正文重点 |
|---|---|---|
| 强趋势分歧 | 龙头还强，跟风掉队，高位股出现大分歧 | 谁抗住、谁掉队、明天看承接 |
| 主线切换 | 旧主线放量走弱，新方向放量接力 | 旧主线失效、新主线证据、切换确认点 |
| 情绪退潮 | 连板高度下降，妖股断板，大面扩散 | 亏钱效应、风险链条、回避条件 |
| 指数护盘 | 指数不差，多数个股弱 | 指数假象、真实宽度、谁在护盘 |
| 消息兑现 | 利好落地不涨，或利空落地不跌 | 价格与情绪背离、资金提前定价 |
| 普涨高潮 | 多主线同时涨，成交放大，一致性强 | 高潮风险、第一次分歧看什么 |
| 缩量震荡 | 没主线、没量、没持续性 | 写短，重点写等待条件 |

输出格式：

```markdown
市场类型：
历史校准：
- 昨天判断：
- 前天/近一周判断：
- 今天验证/修正/推翻了什么：
- 是否写进正文：是 / 否
- 写入方式：
核心矛盾：
今天正文应该围绕：
今天正文不应该写：
今天必须避开的重复句式：
读者能执行的表达：
```

历史校准规则：

- 写作前必须回看最近 1-5 篇复盘、判断卡或 `stock_review_judgements.jsonl`。
- 只校准与今天盘面有关的判断：主线延续、分歧、退潮、低位扩散、风险位、等待条件、核心股承接。
- 可以承认预判正确，也可以承认预判失效，但正文里要写成市场连续性的判断，不写成自我表扬。
- 如果历史判断与今天无关，判断卡里写“无须进入正文”，正文不硬塞。
- 历史回看必须帮助今天的操作计划：继续看、降级看、确认失效、等待下一次修复。
- 写作前必须列出最近文章里已经用烂的表达，并在正文中避开。尤其避免反复使用“前排/后排”“明天怎么看”“看承接”“核心还能拿、后排要减”这类空泛表达。
- 如果内部判断用了“前排/后排”，正文必须翻译成普通读者能执行的标准：什么走势能留，什么走势要减，什么情况等待。

## 二、主线筛选卡

每天重新筛，不固定写任何板块。用户提到的板块只是候选，不等于当天主线。

```markdown
候选方向：
- 方向A：
  - 成交额/量能：
  - 龙头/核心股：
  - 涨停梯队：
  - 横向强度：
  - 近3-5日状态：
  - 结论：主线 / 次主线 / 只观察 / 剔除

- 方向B：
  - 成交额/量能：
  - 龙头/核心股：
  - 涨停梯队：
  - 横向强度：
  - 近3-5日状态：
  - 结论：主线 / 次主线 / 只观察 / 剔除
```

判定要求：

- 主线必须有成交额或龙头承接，不靠涨幅榜。
- 板块内部要有核心股共振，不能只有单票脉冲。
- 近 3-5 日必须看连续性：强化、持平、分歧、退潮、反转。
- 板块命名要精准，不能把不同交易线混写。

### 主线排序规则

如果当天有重大催化，先判断它是否真正改变了盘面定价：

1. **催化强度**：业绩、IPO、政策、订单、价格涨价等是否有官方/可靠来源。
2. **盘面响应**：相关核心股是否放量上涨、涨停、成交额靠前。
3. **扩散层级**：直接受益、产业链受益、情绪映射要分开写。
4. **对比强弱**：不能因为某个分支龙头涨停，就把它排在真正主线前面。

示例：
- 长鑫业绩催化下，兆易创新、佰维存储、大普微、深科技、雅克科技这类属于存储/产业链核心或扩散。
- 华工科技涨停属于 CPO/光模块强分支，但如果中际旭创、新易盛、天孚通信没有同步强，就不能把 CPO 写成全线第一主线。
- 合肥城建、上峰水泥这类更多是情绪映射或投资链条，不能当作主营直接受益股。

主线写作顺序必须跟“催化强度 + 盘面响应 + 产业链直接度”一致。

### 重大催化复核

重大催化不能因为“今天涨幅榜不在最前”就漏掉。只要它在上一交易日或当天显著影响过情绪，判断卡必须单独复核。

```markdown
重大催化：
- 事件：
- 来源级别：官方 / 公告 / 财经媒体 / 传闻
- 昨天或前一交易日的市场反应：
- 今天是否延续：延续 / 弱化 / 兑现 / 被证伪
- 直接受益链：
- 泛概念或被淘汰分支：
- 是否写进正文：是 / 否
- 写入方式：只写盘面影响，不做长篇科普
```

判断标准：

- 如果重大催化昨天点燃情绪，今天没延续，正文要写“情绪没有延续”。
- 如果只剩少数直接受益环节强，正文要写“资金在筛选”，不能写成全线继续强。
- 如果消息很大但盘面不认，正文要写“消息重要，交易上未被继续定价”。
- 如果消息已被充分定价，正文要写兑现风险，不继续拔高。

## 三、关注标的判断卡

只要文章出现“关注、低吸、试错、买入、加仓、可做、参与、推荐”等操作词，必须先填这张卡。

```markdown
标的：
所属主线：

1. 趋势结构：
   - 当前价格与 5/10/20 日均线：
   - 平台/前高/缺口：
   - K线风险（长上影、放量阴线、冲高回落）：

2. 龙头地位：
   - 是否板块核心：
   - 是否带动同板块：
   - 同板块更强/更弱标的：

3. 资金承接：
   - 成交额：
   - 放量/缩量位置：
   - 主动买盘/卖盘或主力流向：

4. 情绪位置：
   - 涨停梯队：
   - 连板/妖股状态：
   - 高位股亏钱效应：

5. 横向比较：
   - 相比同板块核心股强在哪里：
   - 是否只是跟风：

6. 纵向比较：
   - 近3-5日是强化/分歧/退潮/反转：
   - 今天相对前几天的变化：

交易结论：
- 能做 / 等确认 / 回避：
- 触发条件：
- 风险位：
- 失效信号：
```

通过标准：

- 六维至少 4 维支持，才允许写“可关注/可试错”。
- 资金和情绪任一项明显转弱，只能写“等确认”。
- 技术破位且板块不共振，直接剔除。
- 只有消息或单日涨幅，没有资金/情绪/图形确认，不能推荐。

## 四、正文转换规则

判断卡不是正文，不能原样贴进公众号。

写正文时只保留三类信息：

1. 最能支撑核心判断的事实。
2. 读者明天能验证的条件。
3. 和操作有关的点位、信号、失效条件。

不要把“我检查了六维”“根据规则”“用户要求”等内部流程写出来。

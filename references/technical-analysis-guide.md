# 技术面数据写入文章指南

## 核心原则

**不直接贴评分，把数据翻译成判断语言。**

读者不关心某只股票"RSI是68"，他们关心的是"这只股票现在处于强势区间，还没到超买，理论上还有空间"。技术数据是判断的底气，不是文章的主体。

---

## 一、市场状态 → 写进纵向背景

市场状态用来回答"这波行情走到哪了"，放在正文的行情背景段或开头。

**转化规则（每种状态对应的写法）：**

| 状态 | 数据 | 文章写法示例 |
|------|------|-------------|
| 趋势上行 | 20日收益+8.5%，波动率18% | "这波行情从5月6日到今天走了第8个交易日，指数20日累计涨幅8.5%，波动率还在低位，趋势完整。" |
| 温和偏多 | 20日收益+3.2%，波动率22% | "大盘近20日涨了3%多，还在多头区间，但没有明显加速，需要主线带动才能突破。" |
| 震荡整理 | 20日收益+0.5%，波动率15% | "指数这20天基本走平，市场在等一个方向——今天的结构分化就是在做选择。" |
| 高波动 | 20日收益-1%，波动率35% | "波动率偏高，指数方向混乱，今天这波的可持续性要打问号。" |
| 趋势下行 | 20日收益-4%，波动率20% | "大环境偏空，今天的反弹要看成交量能不能承接，否则大概率是超跌回补。" |

**写进文章时：**
- 放在"为什么今天会这样走"段落的开头或结尾
- 一句话足够，不超过30字
- 只说结论，不说"技术面显示"或"数据表明"

---

## 二、情绪分 → 强化行情强度描述

情绪分用来支持你对今天行情强弱的判断，让描述有数字依据而不是纯感觉。

**不合格写法：**
> 今天市场情绪较好，多数板块上涨。

**合格写法（情绪分82，强势）：**
> 今天是今年以来情绪最强的几个交易日之一——涨停134家，两市上涨家数超过3500家，市场宽度极好。

**合格写法（情绪分48，震荡）：**
> 今天上涨家数和下跌家数基本持平，指数涨了但实际很多票没有涨，情绪面没有看起来那么好。

**规则：**
- 不写"情绪分XX分"这种生硬表述
- 把情绪分背后的具体指标（涨停家数、上涨家数）拆出来说
- 情绪分≥70时可以正面描述市场宽度；<40时要提醒行情背后的分歧

---

## 三、个股技术评分 → "明天看什么"的观察条件

这是技术数据最直接的用途：给个股推荐提供量化的观察条件，让读者第二天有具体的验证点。

**翻译规则（每个因子对应的文字）：**

| 技术指标 | 原始数据 | 文章写法 |
|---------|----------|----------|
| 均线多头排列 | `ma_aligned: true` | "均线结构完整，多头排列" |
| 量比 | `vol_ratio: 3.2` | "今日放量3.2倍，资金明显进场" |
| RSI | `rsi: 68` | "RSI处于强势区间（68），尚未超买" |
| RSI | `rsi: 78` | "RSI已经偏高（78），追高有压力" |
| MACD | `macd: 零轴上金叉` | "MACD零轴上方金叉，上行动能充足" |
| MACD | `macd: 多头持续` | "MACD多头延续" |
| 乖离率 | `deviation_pct: 0` | （今日涨停不需要单独说） |
| 乖离率 | `deviation_pct: 8.5` | "当前偏离5日均线8.5%，短期有回调压力" |

**每只股票最多用3个技术数据点，嵌入观察条件里：**

```
❌ 不合格：
长川科技(300604)技术面评分85/100，MA多头排列，量比3.2，RSI 68，MACD零轴上金叉。明天关注连板。

✅ 合格：
长川科技(300604)今日涨停，放量3.2倍，均线多头排列，RSI 68处于强势区间。
明天若高开能维持、不大量开板，说明主力没在兑现，可以继续观察。
若缩量跌破今日开盘价，则短线动能减弱。
```

**写作要求：**
1. 技术数据嵌入"如果...则..."条件句里，不单独列出
2. 量比重点说，是资金进场最直接的证据
3. RSI超过75时必须提醒（不是买入障碍，是追高风险提示）
4. 不写"技术面显示"、"从技术指标来看"这类导语
5. 不对技术评分打分方式做任何解释

---

## 四、哪些情况下技术数据可以放更多

- 行情主因是资金博弈（没有明显产业消息）时：技术面可以作为主要判断依据，多写量比和MACD
- 个股和大盘背离时：RSI/量比用来解释背离原因
- 读者问"这只还能追吗"的场景：用乖离率+RSI回答追高风险

---

## 五、不要这样写

- ❌ "技术面良好，均线多头排列，RSI处于合理区间，MACD金叉，综合评分较高"
  → 堆砌技术词汇，信息密度低
- ❌ "根据技术面分析，该股明日大概率上涨"
  → 技术数据不等于预测，这是技术分析的最常见误用
- ❌ 每只股票都写一段技术分析
  → 只给"明天看什么"章节里的推荐个股写，正文主线分析段不需要

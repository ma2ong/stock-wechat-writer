# A股复盘写作手册

## 目标

把"市场发生了什么"写成"读者为什么该关心它，以及他们愿意转发给朋友"。

---

## 一、写之前必须回答的4个问题

1. 今天市场最强的是谁（有成交量支撑，不只靠涨幅榜）
2. 为什么是它强（产业逻辑 / 政策 / 资金 / 海外映射）
3. 这波强是情绪性、资金性还是产业逻辑驱动
4. 明天最值得盯的一件事（具体且可验证）

## 一a、先判断今天属于哪种盘面

结构跟着盘面走，不跟模板走。写作前先给当天打标签，再决定文章结构。

| 盘面类型 | 识别信号 | 推荐写法 |
|---|---|---|
| 强趋势分歧 | 龙头还强，跟风掉队，高位股大分歧 | 写“谁抗住、谁掉队、明天看承接” |
| 主线切换 | 旧主线放量走弱，新方向放量接力 | 写“旧主线失效、新主线证据、切换确认点” |
| 情绪退潮 | 连板高度下降，妖股断板，大面扩散 | 写“亏钱效应、风险链条、回避条件” |
| 指数护盘 | 指数不差，但多数个股弱 | 写“指数假象、真实宽度、护盘方向” |
| 消息兑现 | 利好落地不涨，或利空落地不跌 | 写“情绪与价格背离、资金提前定价” |
| 普涨高潮 | 多主线同时涨，成交放大，一致性强 | 写“高潮风险、明天第一次分歧” |
| 缩量震荡 | 没主线、没量、没持续性 | 写短，重点提示等待，不硬找机会 |

禁止每天固定用同一套章节。可以参考好稿的判断风格，但不能复制固定骨架。

## 一b、关注标的的硬规则

如果文章涉及"关注标的"或"可操作方向"，先执行趋势过滤。

**只看当前趋势，不做超跌幻想。**

执行顺序固定：

1. 先填 `pre-writing-judgement-card.md`，确认当天市场类型和主线。
2. 再查 `risk-veto-rules.md`，有否决项先回避。
3. 最后才参考 `trading-strategy-playbook.md` 选择龙头、缩量回踩、放量突破、情绪周期等判断模块。

- 强势方向每天重新筛，不固定写 CPO、存储、芯片、电力等某几个板块。
- 用户提到的方向只能作为候选，不等于当天主线。必须自己横向比较全市场强度后再决定写什么。
- 板块标签要精准：算电协同、电力设备、绿电情绪股、红利电力不是一回事，不能混写。
- 低位垃圾股、前期连续弱势股，只涨一天不进推荐池。
- 没有明显趋势反转证据，不要因为当日涨幅靠前就提。
- 推荐池优先放当前强主线里的核心票，而不是防守性凑数。
- 如果主线不能做，就写"暂时回避"，并给出等待点位或确认信号。

**趋势反转至少要有三类证据：**

1. 图形：放量突破平台，或重新站回关键均线后连续 2-3 日不破。
2. 资金：成交额明显放大且回踩缩量，主动买盘强于卖盘。
3. 板块：不是单票独涨，同方向有梯队和核心股呼应。
4. 情绪：板块从亏钱效应转为赚钱效应，断板/大面没有扩散。

没有这些证据，只能写"反弹观察"，不能写"机会"。

**分析维度必须同时覆盖：**

- 盘面：指数、成交额、市场宽度、板块涨跌。
- 情绪：涨停梯队、连板高度、妖股是否断板、高位股亏钱效应。
- 资金：成交额排名、主力流向、主动买卖盘、放量/缩量位置。
- 技术：5/10/20 日均线、平台、前高、缺口、长上影/长下影。
- 横向比较：同板块核心股谁强谁弱，资金是否只抱团一两只。
- 纵向比较：近 3-5 日主线是强化、持平、弱化还是反转。

这是硬性门槛，不是可选项。推荐任何板块或个股前，至少要写清楚：

1. **横向强度**：它比同日其他强势方向强在哪里。
2. **纵向状态**：它相对近 3-5 日是强化、分歧、退潮还是反转。
3. **资金证据**：成交额、量能、主动买盘/卖盘或主力流向支持什么结论。
4. **情绪证据**：龙头、连板、妖股、跟风股、亏钱效应处于什么阶段。
5. **图形证据**：均线、平台、前高、长上影/长下影、放量阴线说明什么。
6. **交易结论**：能做、不能做、等什么信号再做。

缺少以上证据时，只能写“观察/回避”，不能写推荐。

操作建议必须是条件句：

```
如果[核心股/指数/板块]站回[点位/均线/平台]，可以[低吸/试错/加仓]。
如果跌破[风险位]，说明趋势弱化，先回避。
如果没有确认信号，不买，等下一次回踩或突破。
```

## 二、开头写法

**三选一，必须在第一段就给结论：**

### 数字开头
直接扔一个关键数字，后面接反直觉判断。

> 3.25万亿。今年以来第三次破3万亿，但这次不一样——钱去的方向变了。

### 反直觉开头
今天走势和多数人预期不一样时用。直接说出那个不一样的地方。

> 今天指数涨了，但真正持有科技线的人心里清楚——上午那波，很多票是冲高就砸的。

### 判断开头
直接给核心立场，后面论证。

> 今天是一次典型的风格切换。表面普涨，实则资金在做减法——减消费，加科技。

**禁止用的开头：**
- "今日A股市场..."
- "在当前市场环境下..."
- "随着近期政策持续发力..."

## 三、主线段落写法

结构：**谁强 → 为什么强（三层因果）→ 意味着什么**

```
今天成交额最大的板块是[板块名]，[具体数字：成交额X亿，龙头XX涨停/收盘价X]。

[说清楚为什么它才是主线：产业消息/龙头连板/资金流向，选最有说服力的一个]

[这意味着什么：市场在赌什么，还是只是短期情绪]
```

### 驱动逻辑的三层因果（借鉴 alphaear-reporter）

写"为什么强"时，把逻辑链走完，而不是只说结果。三层缺一不可：

| 层级 | 要回答的问题 | 示例 |
|------|------|------|
| **宏观层** | 什么政策/消息/宏观事件触发了这个方向 | 国务院发布数据要素政策 |
| **传导链** | 这个事件怎么传导到具体板块和个股 | 数据资产入表→算力需求→GPU/IDC受益 |
| **市场影响** | 资金实际怎么反应，量能和价格说明了什么 | 算力板块今日成交额X亿，较昨日+40%，寒武纪涨停 |

如果三层中有某层逻辑不通，说明驱动可能是假的，或者市场反应过度——这本身就值得写。

### 情绪与价格背离（借鉴 alphaear-sentiment）

数据采集时留意主要新闻的情绪方向和实际价格走向是否一致：

- **一致**（利好消息+上涨 / 利空消息+下跌）：正常反应，重点写驱动逻辑
- **背离**（利好消息+下跌 / 利空消息+上涨）：**这才是最值得写的**——背离说明市场在交易消息之外的什么，或者消息已被提前定价

背离时的写法：先点出背离事实，再分析背后原因（利好出尽/资金已提前布局/更大利空压制）。

**写主线时必须排除的假强信号：**
- 涨幅榜前三但成交额不大 → 主题炒作，非主线
- 龙头当天大幅冲高回落 → 情绪峰值，非趋势
- 媒体推荐多但实际资金流入少 → 舆论热点，非市场热点
- 前期跌幅巨大、低位只涨一天 → 超跌反弹，非趋势反转
- 单票涨停但板块不跟、核心股不动 → 孤立脉冲，不进推荐池

如遇高位放量长阴、龙头断板、主线核心集体破位、低位只涨一天、单源传闻刺激等情况，风险否决优先，不能为了凑“关注标的”强行给机会。

## 四、明日展望写法

不写"后市值得期待"，写具体可验证的观察点（最多4个）。

**推荐句式：**

```
明天最关键的只有一件事：[具体事件/指标]。
如果[条件A]，大概率[结果A]。
如果[条件B]，就要看[信号X]来判断。
```

示例：
> 明天最关键的只有一件事：科创板的量能能不能接住今天的情绪。如果缩量到1.2万亿以下，这波大概率是脉冲；如果量能继续在1.5万亿以上，主线没走完。

## 五、传播力四维度（写完对照）

好文章不只要写得对，还要让人愿意转发：

### 1. 钩子（标题+开头留人）
读者在标题看到一个让他想知道答案的问题，开头第一段给出一个反直觉数字或判断。

测试方法：把标题和第一段给没看今天行情的人看，他会想继续读吗？

### 2. 信息密度（每段都有价值）
每段要有具体数字、事件或判断，没有废话段落。

测试方法：逐段问"删掉这段，核心判断会损失什么？"，如果答案是"没损失"，删掉。

### 3. 独家立场（别处没有的角度）
读者已经看了财联社、雪球，他们为什么要看你的复盘？

需要有一个别处没有明确说出来的判断或角度。

### 4. 分享单元（一句话可以单独截图）
全文要有一句能独立存在、让人想截图发给朋友的核心结论句。

示例：
> "今天3.25万亿背后，资金在投票：不要消费，要科技。"

## 六、写作提示

句式和结构都不固定，随行情走。以下是几种思路，不是模板：

**主线判断的思路：**
- 从成交额和龙头行为说起，再说市场在赌什么
- 直接点出今天最反常的一件事，然后解释为什么
- 先说多数人的误判，再说自己的判断是什么

**驱动解释的思路：**
- 找到最直接的那个催化（政策/消息/海外），说清楚它为什么有效
- 如果驱动不明确，就老实说"资金行为我看不懂，但盘面是这样的"

**明日展望的思路：**
- 找到明天最容易产生分歧的那一个点，说清楚看多和看空各自的逻辑
- 如果量能是关键，说量能的具体阈值
- 如果龙头股行为是关键，说盯哪几只，看什么信号

**避免格式固化：**
- 不要求每篇都有“先说结论/为什么/主线/明天看什么”这些固定标题。
- 不要求每篇都写同样数量的板块。
- 不要求每篇都从指数写起；如果指数不是重点，可以一笔带过。
- 当天盘面越复杂，越要压缩无关内容，只写最能解释市场的一条线。
- 当天没有好机会，文章可以短，重点写风险和等待条件。
- `0514 强趋势还在，但跟风票开始掉队` 是参考例子，不是模板。学它的结论直接、少废话、围绕强趋势、条件句交易计划；不要照搬它的板块、四段结构或“明天怎么做”章节。

## 六b. 具名案例要求

每篇文章正文里至少出现**2个具名案例**：公司名或股票代码 + 具体数字。

**不合格（抽象）：**
> 科技板块今天表现强势，多只个股大幅上涨。

**合格（具名）：**
> 寒武纪（688256）今天放量涨停，是科技线里最早启动的。中际旭创（300308）午后直接拉至涨停，CPO方向的情绪彻底点燃。

具名的作用：让读者知道你是真的跟了今天的盘，不是在泛泛总结数据。

## 六c. 结尾互动引导（D5 必须有）

结尾固定结构（在风险提示之前加一段）：

**模板：**
```
[今天最值得讨论的问题]——[两个选项或开放性思考]。

留言聊聊，你今天拿的是哪个方向。
```

**示例：**
```
科技这波能走到下周还是只有今明两天的情绪？
留言聊聊，你今天在哪个方向上。
```

规则：
- 用开放性问题，不用是非题
- 引导说自己的仓位或判断，不引导预测指数
- 一句话足够，不要3个问题堆一起

---

## 七、绝对禁用的写法

- "市场表现活跃" → 换成具体指数、成交额
- "投资者情绪显著修复" → 换成涨停家数、市场宽度
- "多个板块实现上涨" → 挑1-2个最重要的说清楚
- "后续行情值得关注" → 明天具体看什么，说清楚
- 把涨幅榜第一直接当主线 → 看成交量和龙头持续性
- 无依据喊单 → 说判断逻辑，不说"一定会涨"
- 把用户指令/纠错过程写进正文 → 公众号只面向读者，不展示内部对话
- 每天套同一套标题和章节 → 根据当天盘面重组结构
- 只看涨跌幅和新闻，不看资金/情绪/图形/均线/龙头结构 → 分析不合格，必须重写

# A股复盘写作手册

## 目标

把"市场发生了什么"写成"读者为什么该关心它，以及他们愿意转发给朋友"。

---

## 一、写之前必须回答的4个问题

1. 今天市场最强的是谁（有成交量支撑，不只靠涨幅榜）
2. 为什么是它强（产业逻辑 / 政策 / 资金 / 海外映射）
3. 这波强是情绪性、资金性还是产业逻辑驱动
4. 明天最值得盯的一件事（具体且可验证）

---

## 二、开头写法

**三选一，必须在第一段就给结论：**

### 数字开头
直接扔一个关键数字，后面接反直觉判断。

> 3.25万亿。今年以来第三次破3万亿，但这次不一样——钱去的方向变了。

### 反直觉开头
先破"表面现象"，再给真相。

> 今天最重要的，不是指数涨了多少，而是主线换了。昨天的消费今天缩量，科技悄悄接棒。

### 判断开头
直接给核心立场，后面论证。

> 今天是一次典型的风格切换。表面普涨，实则资金在做减法——减消费，加科技。

**禁止用的开头：**
- "今日A股市场..."
- "在当前市场环境下..."
- "随着近期政策持续发力..."

---

## 三、主线段落写法

推荐结构：**谁强 → 为什么强 → 意味着什么**

```
今天最强的是[板块名]。

不是因为涨幅排第一，而是[成交额/龙头连板/产业消息]。
[具体说明：成交额X亿，较昨日+X%；龙头XX涨停/收盘价X]

这意味着[结论：市场在赌什么/资金在做什么判断]。
```

**写主线时必须排除的假强信号：**
- 涨幅榜前三但成交额不大 → 主题炒作，非主线
- 龙头当天大幅冲高回落 → 情绪峰值，非趋势
- 媒体推荐多但实际资金流入少 → 舆论热点，非市场热点

---

## 四、明日展望写法

不写"后市值得期待"，写具体可验证的观察点（最多4个）。

**推荐句式：**

```
明天最关键的只有一件事：[具体事件/指标]。
如果[条件A]，大概率[结果A]。
如果[条件B]，就要看[信号X]来判断。
```

示例：
> 明天最关键的只有一件事：科创板的量能能不能接住今天的情绪。如果缩量到1.2万亿以下，这波大概率是脉冲；如果量能继续在1.5万亿以上，主线没走完。

---

## 五、传播力四维度（写完对照）

好文章不只要写得对，还要让人愿意转发：

### 1. 钩子（标题+开头留人）
读者在标题看到一个让他想知道答案的问题，开头第一段给出一个反直觉数字或判断。

测试方法：把标题和第一段给没看今天行情的人看，他会想继续读吗？

### 2. 信息密度（每段都有价值）
每段要有具体数字、事件或判断，没有废话段落。

测试方法：逐段问"删掉这段，核心判断会损失什么？"，如果答案是"没损失"，删掉。

### 3. 独家立场（别处没有的角度）
读者已经看了财联社、雪球，他们为什么要看你的复盘？

需要有一个别处没有明确说出来的判断或角度。

### 4. 分享单元（一句话可以单独截图）
全文要有一句能独立存在、让人想截图发给朋友的核心结论句。

示例：
> "今天3.25万亿背后，资金在投票：不要消费，要科技。"

---

## 六、推荐句式库

**主线判断：**
- 今天最重要的，不是X，而是Y
- 如果只看涨幅榜，很容易误判——真正带动情绪的，其实是……
- 这意味着市场在做一次风格切换

**驱动解释：**
- 背后是[具体消息/政策]——这才是今天[板块]异动的根本原因
- 资金在下注的，不是[表面叙事]，而是[深层逻辑]

**明日展望：**
- 明天最关键的，不是指数还能不能涨，而是主线分歧后的承接
- 如果量能继续维持高位，主线大概率没走完
- 如果核心票分歧明显加大，就要看板块内部是否转向高低切

---

## 六b. 具名案例要求

每篇文章正文里至少出现**2个具名案例**：公司名或股票代码 + 具体数字。

**不合格（抽象）：**
> 科技板块今天表现强势，多只个股大幅上涨。

**合格（具名）：**
> 寒武纪（688256）今天放量涨停，是科技线里最早启动的。中际旭创（300308）午后直接拉至涨停，CPO方向的情绪彻底点燃。

具名的作用：让读者知道你是真的跟了今天的盘，不是在泛泛总结数据。

---

## 六c. 结尾互动引导（D5 必须有）

结尾固定结构（在风险提示之前加一段）：

**模板：**
```
[今天最值得讨论的问题]——[两个选项或开放性思考]。

留言聊聊，你今天拿的是哪个方向。
```

**示例：**
```
科技这波能走到下周还是只有今明两天的情绪？
留言聊聊，你今天在哪个方向上。
```

规则：
- 用开放性问题，不用是非题
- 引导说自己的仓位或判断，不引导预测指数
- 一句话足够，不要3个问题堆一起

---

## 七、绝对禁用的写法

- "市场表现活跃" → 换成具体指数、成交额
- "投资者情绪显著修复" → 换成涨停家数、市场宽度
- "多个板块实现上涨" → 挑1-2个最重要的说清楚
- "后续行情值得关注" → 明天具体看什么，说清楚
- 把涨幅榜第一直接当主线 → 看成交量和龙头持续性
- 无依据喊单 → 说判断逻辑，不说"一定会涨"
